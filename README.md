# 🌊 Mar Azul

Sitio web de alquiler de departamentos temporarios frente al mar.

## 📋 Descripción

Mar Azul es una página web desarrollada con HTML, CSS y JavaScript que permite mostrar información sobre departamentos temporarios, servicios, ubicación y medios de contacto para los visitantes.

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- Visual Studio Code

## 📂 Estructura del proyecto

```
MAR AZUL/
│
├── img/
│   └── Imágenes del sitio
│
├── Departamentos/
│   └── Información de departamentos
│
├── contacto.html
├── departamentos.html
├── index.html
├── nosotros.html
└── styles.css
```

## 🏠 Secciones del sitio

- **Inicio**: presentación principal del complejo.
- **Departamentos**: muestra los alojamientos disponibles.
- **Nosotros**: información sobre Mar Azul.
- **Contacto**: formulario y datos de contacto.

## 🎨 Características

- Navegación simple e intuitiva.
- Galería de imágenes.
- Información de servicios y ubicación.
- Formulario de consultas.

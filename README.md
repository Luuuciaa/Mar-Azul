# 🌊 Mar Azul

Sitio web de alquiler de departamentos temporarios frente al mar.

## 📋 Descripción

Mar Azul es una página web desarrollada con HTML y CSS que permite a los visitantes conocer los departamentos disponibles, sus características, servicios, ubicación y realizar consultas o solicitudes de reserva de manera sencilla.

## 🚀 Tecnologías utilizadas

* HTML5
* CSS3
* Visual Studio Code
* Boxicons
* Font Awesome

## 🏠 Secciones del sitio

* **Inicio:** presentación principal del complejo.
* **Departamentos:** muestra los alojamientos disponibles.
* **Detalle de departamentos:** información completa de cada alojamiento.
* **Nosotros:** información sobre Mar Azul.
* **Contacto:** formulario y datos de contacto.
* **Reserva:** formulario para solicitar una reserva.
